Graph Explorer JSON Query

  1. Open Graph Explorer and run any query.
  2. The results area splits in half — the JSON Query panel appears on the right (use the button in the bottom-right corner to show it again if hidden).
  3. Type a JMESPath expression (like Azure CLI --query) in the top box; the filtered result appears below it.
  4. Copy or download the result as JSON or CSV.

Example: value[].{name: displayName, email: mail}
